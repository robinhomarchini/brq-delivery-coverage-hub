# Contexto para IA

A aplicação deve apoiar decisões de capacidade e cobertura. Os primeiros casos de
uso previstos são: sobrecarga de managers, territórios descobertos, rebalanceamento
de portfólio e resumo executivo.

As funções em `src/lib/ai/insights.ts` são placeholders determinísticos. Não devem
ser tratadas como recomendações reais enquanto não houver dados confiáveis,
governança e validação humana.
