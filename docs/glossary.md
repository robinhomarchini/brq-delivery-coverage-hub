# Glossary

- Baseline: approved reference value used for comparison.
- Board baseline: official target baseline approved for the year.
- Cliente: customer/account.
- Hunter: role responsible for new business or Hunter target.
- Farmer: role responsible for renewal/amplification.
- Delivery: role responsible for delivery governance.
- Studio Hunter: studio breakdown that composes Hunter analysis without duplicate counting.
- Studio Manutencao: renewal/maintenance studio allocation.
- Snapshot: saved photo of a calculated report result.
- RLS: Supabase Row Level Security.
- BFF: backend-for-frontend boundary for critical server-side rules.
