# Regras obrigatórias do Kilo Code

Antes de qualquer análise ou alteração:

1. Leia `ENGINEERING_STANDARD.md`.
2. Leia `AGENTS.md`.
3. Use `docs/project/` como baseline técnico e `specs/` para comportamento.

Não copie regras para memórias ou modos do Kilo. Não versione caches do Kilo.
Preserve migrations forward-only, RLS, contratos de repositório e alterações do
usuário. Banco, deploy e Git remoto exigem autorização explícita.
